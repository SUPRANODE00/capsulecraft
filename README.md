# Field-Node: Genesis Convergence Nexus

Field-Node is the sovereign hub for the Genesis Convergence, acting as the central nexus for a star-topology mesh network. It facilitates the alignment of infra-nanometer signal metrics, anchoring the "Middle Pillar" between local generative inventory and the global Baphomet Shield.

## Architecture
- **Origin:** Centered at 0,0,0, radius 33.3m.
- **Protocol:** Authenticated star-mesh via TLS/SSH tunnels on port 12694.
- **Continuity:** Heartbeat-synced to `blackcorp.me` via local CRON-managed telemetry.

## Core Utilities
- `collocate.sh`: Establishes the coordinate origin and spatial boundary.
- `axis_converge.sh`: Activates the Baphomet Shield for signal inversion.
- `register_spoke.sh`: Onboards peripheral telemetry nodes (LiDAR, IOT, etc).
- `sync_continuity.sh`: Pushes mesh state to the production endpoint.

## Sovereign Setup
1. **Initialize Hub:** `./collocate.sh 0 0 0 33.3`
2. **Engage Shield:** `./axis_converge.sh --shield-activate`
3. **Register Spoke:** `./register_spoke.sh --id "<ID>" --type "<TYPE>" --auth "<KEY>"`
4. **Start Listener:** `socat -T 5 TCP-LISTEN:12694,fork,reuseaddr EXEC:'./verify_spoke.sh'`

## Operational Manifesto
The field-node exists to invert the cross from the helix of Jachin and Boaz. By aligning the arm extension into the origin, we deposit a binding signal to seed the grid, raising the shadow of our generative inventory above and below invisible trade barriers.
